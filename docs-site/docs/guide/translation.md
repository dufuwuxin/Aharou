# 离线翻译

离线翻译用于在设备上进行英文→中文、中文→英文的文本转换，不会把待翻译正文发给翻译服务。应用界面仍为中文，翻译方向不改变应用语言。

## 下载与使用

首次使用某个方向前，需要联网下载该方向的模型。两个方向分别准备；下载一个方向并不代表另一个方向已经可用。英文→中文模型约 119.5 MB，中文→英文的具体下载大小以应用显示为准。

下载完成并通过完整性检查后，该方向可离线使用。切换方向时应用会释放前一个方向的推理实例，再加载所选方向；首次加载和切换可能需要等待，设备内存与正文长度会影响耗时。

## 保持正文结构

代码块、行内代码、链接地址、文件路径、变量与占位符等技术内容应保留原文。普通说明文字交给离线模型处理；翻译不可用时保留原文，不要把原文误认为已完成翻译。

机器翻译可能误解专业术语、否定句或上下文。涉及命令执行、配置、安全说明时，请对照原文核查，不要直接依据译文执行高风险操作。

## 失败处理

- 下载失败：检查网络和剩余空间，再重试相应方向；未经校验的下载不会当成可用模型。
- 离线时提示模型缺失：先联网完成该方向的下载，再回到离线环境使用。
- 切换后无法翻译：等待模型加载完成，必要时重试；错误时保留原文。

## 质量验证边界

当前设备端与云端质量脚本均保留贪心解码（`num_beams=1`、`do_sample=false`、`max_new_tokens=256`）。此前固定版本模型的四例回归中，`num_beams=3` 将“网络连接失败。”误译为临时目录错误，未通过原有概念检查，因此不采用该参数，也不宣称质量提升。历史失败报告保留；后续报告如实记录基线与候选参数及真实输出，仍须通过全部四例概念检查。

维护者可手动运行独立的模型质量工作流。它校验固定版本模型的文件大小和 SHA-256，并记录真实推理输出与有限的概念检查结果，不代表所有场景的翻译质量，也不是 BLEU 分数。云端 Node 推理通过不能替代 Android WebView 上的加载、内存和离线设备验证。模型质量工作流不会自动发布或替换应用中的模型版本。
