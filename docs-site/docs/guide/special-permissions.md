# 特殊权限

「设置 → 特殊权限」集中提供影子屏、配置审计、系统权限和团队修改权限入口。系统授权仍由 Android 或 Shizuku 管理，打开这个页面不代表已经授权。

## 团队修改地址

默认关闭，不会出现在 AI 的默认提示或配置字段目录中。开启后只为当前工作区生成一小时有效的地址；你主动复制给 AI 后，AI 才能使用。关闭或重启会撤销旧地址，重新开启生成新地址。不要把地址发给无关人员。

复制内容可以直接交给 AI，通过已有 `config` 通道读取：`action=get`，`path` 使用复制的 `aharou-team://…/` 地址。它会返回允许修改的字段地址；再读取具体字段可以获得 `revision` 和当前值。

修改时使用 `action=set`、具体字段地址，并将 `value` 设为 JSON 编码的 `{ "expectedRevision": "刚读取的版本", "value": 新值 }`。过期、撤销、跨工作区和旧版本请求均会拒绝，不会自动重试。

此通道只修改项目级团队的流程边和阶段通信参数，继续使用现有团队校验与配置审计；不开放命令执行、任意文件、供应商凭据、全量配置、日志、明文读取或删除。正在执行的团队不因修改预设而暗中换实现，新预设供后续运行使用。关闭操作会在后台等待已进入提交的操作结束，界面不会等待磁盘锁；已经提交的修改不自动回滚，审计中可查看。

## 影子屏状态

创建显示、截图、坐标输入与读取控件是不同能力。某些设备不允许 shell 连接 UiAutomation；此时先尝试已由用户授权的无障碍服务读取同一个影子显示，不会退回主屏。仍不能读取时会说明原因，可使用截图和像素坐标操作，不把未知控件树当成空页面。
