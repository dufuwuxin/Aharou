# 环境变量

「配置 → 凭据与环境变量 → 环境变量」可以定义全局环境变量，它们会注入到**容器内启动的所有进程**：终端、Agent 与子代理执行的命令、面板脚本、MCP 的 stdio 服务器、Git 操作。

值保存时即加密（AndroidKeyStore + AES-256-GCM，密钥与设备绑定），列表里默认打码显示。换机或清除数据后旧密文解不开，需要重新填。

## 添加与编辑

- 名称只能用字母、数字、下划线，且不能以数字开头；不能重名。
- `PROOT_TMP_DIR`、`PROOT_LOADER`、`PROOT_LOADER_32`、`PROOT_NO_SECCOMP`、`LD_PRELOAD`、`LD_LIBRARY_PATH` 是容器的关键变量，不允许占用。
- 「敏感值（列表打码显示）」默认勾选，只影响列表里的显示，值本身始终加密存储。
- 变量名就是主键，**编辑时改不了名**，要改名只能删掉重建。
- 修改只对**之后新启动**的进程生效，已经开着的终端不受影响。

## 优先级

同名变量出现多次时，靠后的覆盖靠前的：

1. 全局环境变量（本页）
2. 容器自己的环境变量（「容器与镜像」里按容器配的）
3. 具体调用方传入的变量（例如某个 MCP 服务器自己的 `env`）

## 别和另外几套环境变量搞混

界面上有四套长得很像的东西，其实各管各的：

::: v-pre
| 哪一套 | 在哪配 | 管什么 |
| --- | --- | --- |
| 全局环境变量（本页） | 配置 → 凭据与环境变量 → 环境变量 | 容器内启动的所有进程 |
| 容器环境变量 | 设置 → 容器与镜像 | 只对该容器镜像的启动生效 |
| 面板脚本参数 | 设置 → AI 供应商管理 → 某个供应商的「面板脚本」 | 以 `AICODE_KEY_<名称>` 注入面板脚本，额外支持 <code v-pre>{{PROVIDER_API_KEY}}</code> 等占位符；脚本路径本身也可经配置通道读写（`providers.<id>.panel_script`） |
| MCP 服务器 env | 设置 → AI 配置 → MCP | 只注入该 MCP 的 stdio 进程 |
:::

本页这套**没有任何内置变量**，初始是空的；也不会做占位符替换，写什么就是什么。

## 与凭据库、关键词替换的区别

两种数据已放在同一个管理页，切换「凭据与关键词」和「环境变量」即可，不需要来回找两个入口。合并的是管理入口，不会把已有密钥复制成环境变量，也不会修改已有保存位置。

- **凭据**：可添加多条名字与原值。连接器引用 <code v-pre>{{vault:名字}}</code>，只在原来允许使用密钥的位置解析；不会自动导出给所有命令。
- **环境变量**：脚本和终端通过 `$名字` 读取，作用于新启动的容器进程。已有进程不会自动更新。
- **模型关键词替换**：将需要替换的词或文本保存为一条具名凭据，启用该条目的「将此条目作为模型关键词替换」，再打开「发送给模型前脱敏」。新请求按精确文本匹配，不把输入当正则；不同原值使用不同的稳定占位符，同一原值重复出现使用同一标记，回复在本机还原。此选择不授予工具读取密钥的权限。

「发送给模型前脱敏」控制请求正文的本地替换及回复还原；「工具结果与日志额外脱敏」控制工具结果、日志和审计中的额外识别。两者范围不同，不需要合并成一个开关。凭据库已有的密钥保护不会因关闭额外识别而取消。

「多条关键词替换」按卡片逐条编辑：每张卡片保存一段完整原文，点「添加一条」继续，不需要用逗号或换行充当分隔符；原文本身可以包含逗号、换行和正则符号。输入默认可见，仅在本机编辑，不会自动向模型发送。保存后才更新选择，取消不修改；删卡片只停用该条替换，保留原凭据。原先容易混淆的单个“本地预览用示例文本”框已移除。设置页不再重复提供管理入口。实际请求只有在对应开关开启时，才替换被选择的内容，不是将全部输入打码；图片和签名原文不作文本替换。
