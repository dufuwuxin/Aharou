# 插件与连接器

插件与连接器直接列在设置首页；技能、MCP 和知识库保留在配置页。

入口：**设置 → 插件**或**设置 → 连接器**。

插件页分为**已安装**、**包市场**与 **Operit2** 三个页签：已安装保留本地导入、启停和卸载；包市场提供 Aharou 插件安装与更新；Operit2 提供对方公开市场的浏览、下载与兼容技能导入。连接器在连接器页配置。原扩展聚合页已移除，其他能力从配置页各自的入口进入。

## 五类分别是什么

| 类型 | 是什么 | 要不要额外权限 |
| --- | --- | --- |
| 插件 | 跑在容器里的扩展服务（`.txplugin` 包），App 只负责装、起、停、卸 | 需要容器可用（首次会自动安装容器）；常驻服务占端口 |
| 技能 | 一份 `SKILL.md` 指南，AI 遇到相关任务时才加载 | 不需要，纯本地文件 |
| MCP 服务器 | 接入的外部工具服务（HTTP 或本地 stdio） | 远程 HTTP 可能需要密钥 / OAuth 授权，在 MCP 页配 |
| 知识库 | 一个远端 Markdown 仓库，同步到本地供 `knowledge_search` 检索 | 不需要；出厂源不可删，自己加的源可在知识库页移除 |
| 连接器 | 内置的 MCP 接入模板（含鉴权方式），一键接成工具 | 接入后按服务要求授权（OAuth / 密钥） |

## 状态怎么读

列表里每条右侧有一个状态词，含义按类型略有不同：

- **运行中** — 插件的常驻服务正在跑（端口探测通过）。卡片上有「停止」。
- **已安装** — 已经装好了。插件在此状态下会显示「启动」；技能、知识库、连接器则不需要再做什么。
- **有可更新版本** — 可比较的数字版本中，市场版本确实比本地新；详情中可确认更新。相同版本显示「已安装相同版本」，本地较新时不提供降级安装；自定义、预发布或缺失版本显示「版本顺序未知」，不会冒称最新。
- **可用** — 还没有装（市场里可安装的插件），或者是不带「安装」概念的出厂知识库源。
- **失败** — 插件上一次启动失败，卡片副标题会带出原因。

每种类型在卡片副标题里都写了一句说明，比如「内置接入模板，无需安装」「出厂源，始终启用、不可删除」，照那句话读就不会误以为连接器也需要装。

## 插件市场

在**设置 → 插件 → 包市场**中搜索名称、描述或标签。列表展示真实索引中的名称、版本、作者、描述和来源，也会标出已安装版本与可确定的更新状态。当前实现只查询源清单里的**第一个来源**，页内明确显示该来源，不能当成所有源的完整搜索结果。

1. 点击条目打开详情，核对描述、来源、版本、标签和下载目标。下载地址会隐藏用户信息、查询参数和片段，避免回显凭据；实际下载仍使用来源提供的地址。
2. 详情明确提示：**将下载包并在当前容器执行其安装脚本**。只有点击「确认下载并安装所示版本」或「确认下载并更新」才会开始；关闭详情、返回或切换页签不会安装。
3. 仅信任来源后再确认。版本顺序未知时会提示可能覆盖本地版本，只有手动确认才安装，不将它标为已确认更新。缺少下载地址时禁用安装并解释原因。
4. 安装期间其他安装、导入、启停和卸载暂不可用；切换页签仍显示处理中提示，操作不会因切页中断。成功后刷新已安装列表与版本，失败保留详情并允许重试。脚本失败可能留下部分内容，请在已安装页检查。

- 只支持 `.txplugin` 容器插件包；借鉴市场交互不代表兼容 Operit 或 Rust 宿主插件，不会复制执行对端宿主插件。
- 市场操作复用原安装流程，不额外触发插件启动。安装脚本本身会执行命令，因此不能将安装视为仅下载文件。
- 市场列表由来源的索引文件驱动。加载中显示进度；网络或格式失败显示错误与「重试加载」；来源确实为空和搜索无匹配有不同提示。「刷新市场」可重新拉取。
- 切换页签保留搜索词、滚动位置和详情状态，不重复自动拉取已加载索引。

想装自己的本地 `.txplugin` 文件，在**已安装**页点击「导入插件包」，仍走原导入及安装流程。服务型插件安装后可在该页手动启动、停止或卸载。

## Operit2 公开市场

进入插件页的 **Operit2** 页签，按技能、脚本、ToolPkg 包或 MCP 筛选，用上一页／下一页翻看真实目录；搜索框只过滤当前页，不声称全市场搜索。目录来源与生成时间显示在页面上。

点击条目可查看作者、版本、说明、来源与最新版本资产。点击「保存文件…」后由系统选择保存位置，取消选择不会下载或导入。发布方提供校验和时会核验后再保存；没有校验和会明确标注未核验。下载不执行任何内容，也不会自动安装插件。

符合 ZIP/Markdown 格式的技能可另点「导入技能」，沿用全局技能库的原生导入，保留已有同名技能。来源为 GitHub 仓库且没有最新发布资产时，可下载其默认分支或来源明确指定的分支源码；有指定子目录时，导入只读取该目录。源码可能不同于市场发布版本，页面会说明，不能把它当作版本已核验的发布包。

Operit 的 ToolPkg 和宿主脚本依赖不同的 API，当前仅提供下载，不把它们伪装成 `.txplugin` 安装。MCP 资源下载也不自动创建 MCP 服务；服务接入仍走原有 MCP 页面。第三方技能内提到的工具、命令和环境不一定在 Aharou 可用，导入成功不代表执行兼容。

## 插件升级和失败恢复

`.txplugin` 导入先写暂存区，不提前删除正在使用的文件。安装步骤、自检、退出码或安装记录保存失败时恢复本次升级前的受管文件和记录；同一暂存包可以重试。顶层 `data` 持久数据不会为了回滚被清空。恢复本身失败时保留备份和错误，不能声称恢复成功。

卸载会检查停止与卸载脚本结果，非零退出或超时不进入目录和记录删除阶段，保留可重试状态。插件脚本对容器其它目录、外部服务或持久数据产生的副作用无法由文件回滚完全撤销；这里不是掉电恢复事务，也不将 Operit 的任意包格式冒称为原生可执行插件。
