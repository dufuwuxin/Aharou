# 项目长期目标与过程树

项目内部工作台使用固定标题与交付进度栏，更多操作与当前项目并列，不再使用脱离布局的悬浮菜单。任务树与地图、分支选择、完整过程阅读和执行控制沿用原有入口。底部横向拖动会取消已过期的滚动任务，松手后只保留一次回弹；真机帧率改善仍需设备实测。

项目与普通会话共用模型、工具和权限。项目另外保存总目标、验收标准、期限以及任务依赖。底部点「首页」，在同一页的「项目」和「会话」分区浏览两类记录。两个分区可以分别上下滚动。

## 一级导航与任务视图（本轮候选，未发布）

以下为本轮候选交互，源码与真机交互验收尚未完成，不代表已安装版本已经具备：

- 「首页／配置／设置」是三个一级根页。底栏点击可打开对应页面，首页正文同时显示项目和普通会话。
- 任务区首次进入默认任务树，而非思维导图。点击任务展开子任务及参与成员、执行记录和修改追踪；仍可从视图菜单切换思维导图。查看操作历史保留原记录详情入口，不用导图代替记录内容。
- 任务或成员名称不是执行证明；只显示关联到该任务、该成员会话的真实记录。没有文件修改记录时应显示暂无记录或未知，不能从一段计划推断成员已经修改文件。文件记录也不等于当前文件正文，需要核实当前内容时仍应打开文件。

首页「会话」分区按工作区分组显示普通会话。打开会话会恢复其绑定的工作区；已有会话的工作区迁移从会话行尾操作进入。项目内会话从对应项目查看。右下角点「添加」可创建项目，也可在新建普通会话时选择已有工作区或创建新的工作区；不选择时使用默认工作区。

任务区右上角保留操作菜单。右上角「会话诊断」打开诊断面板，项目概览和完整任务会话仍从菜单进入；项目主记录可展开根节点查看，系统返回功能保留。

## 查找项目

点首页「项目」分区标题旁的放大镜，按项目名称、目标、要求或工作目录查找。列表显示当前匹配数与项目总数。点「清除」会恢复完整列表并收起输入框。搜索期间仍可浏览普通会话或从右下角创建项目。

## 会话诊断

从操作菜单打开“会话诊断”，在同一页上下滚动查看上下文、主记录（项目会话）、会话地图、活动与上下级成员。默认只展开上下文；点击分区标题可分别展开或收起，多项可以同时展开。普通会话不显示项目主记录分区。

较长的注入正文、记录和成员消息在各自区域内滚动，顶部关闭按钮始终可用。切换会话后，诊断恢复为只展开上下文，活动与成员仍限定在当前会话。项目内会话地图保持只读；普通会话中可定位的节点仍能跳回聊天位置。项目根节点保留主记录查看，菜单不再单独提供主记录阅读项。

本轮候选将「上下级成员」改为可上下扫读的层级列表，替代横向小胶囊；选中成员后查看其实际消息、工具记录和可关联的文件修改，并核对所属任务。该交互仍待源码与运行验收。切换成员不代表启动、重跑或验收任务；切换会话后不得沿用上一会话的成员记录，缺关联时明确显示未知或暂无记录。

## 总目标与期限

从项目概览设置总目标、验收标准和短期／中期／长期。空项目也能设置，删除某个任务不会删除项目目标；旧项目缺少这些字段时继续兼容。修改目标语义会使旧目标下的任务交付失效，历史会话保留，不把旧成果当作新目标已完成。

期限决定一次运行的任务数与总时间预算，不代表无限自动聊天。现有执行器会按依赖推进成员任务；任务耗尽后，中长期项目在预算内调用原规划器，根据目标、验收和已有证据生成具体下一阶段提案。提案需要确认，不把成员交付或待验收状态冒充项目完成。超预算、阻塞、缺验收或规划不可用时会明确记录阶段状态。当前不承诺 App 被系统终止后自动跨重启执行。

## 实时过程树

项目会话默认把真实公开消息和工具事件组织为“目标 → 计划 → 工具 → 结果”，持续更新运行状态；点节点展开原文，仍可切回完整原始会话。它不是模型隐藏思维，也不会凭空制造工作步骤。运行中尚未结束的公开回复不标为最终结果。

## 双指缩放

导图使用双指缩放与拖动，不再显示放大、缩小或重置按钮。节点缩放和平移采用绘制层变换，文本布局不跟每一帧手势重复缩放。实际设备帧率与复杂图手势仍需按设备验证，不能仅凭静态代码保证流畅度。

## 上下文按文件索引

原文字时间线、工具调用顺序和图片所属消息保持不变。发送给模型时额外建立按文件聚合的修改索引，较早且被后续回执替代的成功大修改回执可折叠；失败、图片、通知和最新状态保留，原始历史不会被删除。索引不是文件当前正文，需要查看实时文件时仍用文件读取工具。

## 真实团队执行

新项目优先调用真实团队：概览可填写已有团队名称，`auto`／留空按名称顺序选择第一个通过现有团队构建校验的团队，选择原因随回执保存；显式名称不存在或没有可运行团队时明确阻塞，不回退为默认单成员。旧项目已显式填写 owner／members 的任务保留直接成员执行；旧项目没有成员的任务也必须调用可用团队。

项目仍使用原团队阶段执行器和流水线，不另建调度器。只有团队返回 `done`、真实运行编号和非空成员产出后，任务才进入待验收（不是完成）。团队名称、配置或需求变化会使旧交付失效；团队回执、运行编号及需求版本保存在任务证据和摘要中。停止项目会取消原团队调用并停止其已创建子成员，迟到回执不能覆盖新需求版本。

## 创建项目与会话目录

创建项目会分配独立目录，不切换当前聊天、消息或全局工作区。从项目列表打开项目后再进入该项目自己的会话。

普通会话创建时可以选择已有可用工作区或创建新的工作区。打开会话会恢复它绑定的目录；运行中的会话不能迁移，项目和子代理会话继续跟随原项目目录。迁移操作不搬迁历史附件或源文件。

## 删除任务节点

选中导图或树中的普通任务，可删除该节点及全部子节点；需求分支也可删除。其他任务仍依赖这些节点时，会明确拒绝且不停止正在进行的工作，先修改依赖后可重试。删除成功会停止该项目执行并拒绝已删除任务的迟到回写，历史会话、Git 分支和源码文件均保留。

### 普通会话与团队执行记录

首页点「添加 → 新建会话」，选择工作区后只复用该工作区内、没有消息且不属于项目的普通根会话；不选择则使用当前可用工作区，没有可用默认目录时可先创建工作区。项目主记录、任务讨论和成员执行记录即使为空也不会被复用或作为普通空会话回收；项目的迟到加载不会覆盖新选择的普通会话。

任务由已配置团队执行时，导图节点关联该轮实际创建的成员会话与角色。展开过程可查看这些真实记录及本轮结果；补充需求、删除任务或取消后，旧成员的迟到结果不能重新创建任务，也不会把历史成员记录批量改为成功。团队继续使用原有执行、审核和证据门禁。


### 一级页面普通滑动

首页正文包含项目和普通会话两个分区。一级页面之间既可点底栏，也可在页面内容区左右滑动；设置详情内仍保留各自子页，切回时不会丢失。底栏可拖动到目标页面。图表、导图等多指手势由内容控件优先处理。设备端手势边界仍待真机验收。
