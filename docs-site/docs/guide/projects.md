# 项目长期目标与过程树

项目与普通会话共用原有模型、工具和权限，但另外保存总目标、验收标准、期限以及任务依赖。项目列表中左右滑动可以切换项目与会话，原来的标签按钮仍可使用。

## 总目标与期限

从项目概览设置总目标、验收标准和短期／中期／长期。空项目也能设置，删除某个任务不会删除项目目标；旧项目缺少这些字段时继续兼容。修改目标语义会使旧目标下的任务交付失效，历史会话保留，不把旧成果当作新目标已完成。

期限决定一次运行的任务数与总时间预算，不代表无限自动聊天。现有执行器会按依赖推进成员任务；任务耗尽后，中长期项目在预算内调用原规划器，根据目标、验收和已有证据生成具体下一阶段提案。提案需要确认，不把成员交付或待验收状态冒充项目完成。超预算、阻塞、缺验收或规划不可用时会明确记录阶段状态。当前不承诺 App 被系统终止后自动跨重启执行。

## 实时过程树

项目会话默认把真实公开消息和工具事件组织为“目标 → 计划 → 工具 → 结果”，持续更新运行状态；点节点展开原文，仍可切回完整原始会话。它不是模型隐藏思维，也不会凭空制造工作步骤。运行中尚未结束的公开回复不标为最终结果。

## 双指缩放

导图使用双指缩放与拖动，不再显示放大、缩小或重置按钮。节点缩放和平移采用绘制层变换，文本布局不跟每一帧手势重复缩放。实际设备帧率与复杂图手势仍需按设备验证，不能仅凭静态代码保证流畅度。

## 上下文按文件索引

原文字时间线、工具调用顺序和图片所属消息保持不变。发送给模型时额外建立按文件聚合的修改索引，较早且被后续回执替代的成功大修改回执可折叠；失败、图片、通知和最新状态保留，原始历史不会被删除。索引不是文件当前正文，需要查看实时文件时仍用文件读取工具。
