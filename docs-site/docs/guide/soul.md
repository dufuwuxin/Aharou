# 每轮背景与助手设定

希望助手每轮了解的偏好、角色背景与表达方式，直接在[记忆库](/guide/memory)的「注入类」新建条目。不需要单独维护设定页面，也没有名字与头像入口。

## 写清需要使用的内容

条目包含标题、一句话说明与正文。注入类默认尝试带入全文，可以按需要改为摘要索引、仅检索或停用。必须遵守的行为要求也可以单独保存到规则类，避免同一段要求维护多份。

全局条目可跨项目使用；只适用于某个项目的背景，应选择项目范围。只属于某次对话的材料，应放到临时存放类并绑定目标对话。

## 检查是否带入

保存后在「注入预览」核对正文与未带入原因。内容仍受预算、待确认状态和对话隔离约束；保存成功不等于实际请求已采用，也不会改变工具权限。
