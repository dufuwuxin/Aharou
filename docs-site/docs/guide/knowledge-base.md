# 长期资料

以后还会使用的事实、项目材料与经验，直接保存在[记忆库](/guide/memory)的「长期类」。新库只管理原生条目，不将外部资料库或其他页面接成来源。

## 保存与组织

新建条目时填写清楚的标题、一句话说明和正文，可以用文件夹按项目或主题分组。全局资料可跨项目使用，项目资料只属于当前工作区。

长期类默认「仅检索」，不占每轮上下文；需要每轮提供摘要时可改为「摘要索引」。不要为了让助手看到资料就把整份教材设为正文常驻，全文与索引都有预算。

## 查找与核实

在内容库搜索标题或正文，也可以让助手先搜索、再读取命中的条目。资料中的内容不等于已验证事实，参考文字也不等于执行授权。更新前读取最新版本，确认后再保存。

「注入预览」显示当前任务与目标对话下的规划结果。保存不代表已实际加载，也不承诺跨设备同步。
