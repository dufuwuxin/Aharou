# 外观与语言

应用界面固定中文，配色采用澄蓝。不再提供语言、皮肤、自定义配色或动态取色选择。旧版本的英文、其他皮肤和莫奈设置，以及旧备份里的这些配置，升级或恢复后都不会改变中文澄蓝。

## 工作台与视觉层次

新版以澄蓝作为操作强调色，浅色页面采用中性浅灰底、白色内容卡片与更清楚的文字层次。项目首页增加「我的工作台」标题；没有项目时提供创建说明和按钮。项目与会话入口、右下角新建菜单、项目长按操作和旧工作区续接都保留。

创建项目仍只需名称与用途，不会因为界面更新而提前调用模型。项目卡片优先展示标题、用途与任务数，较长路径和正文收起为摘要。

## 明暗模式

在「设置 → 外观主题」选择自动、深色或浅色；默认自动跟随系统，三种模式均使用澄蓝配色。

### 聊天外观

我的气泡和助手气泡分开设置：

- **我的气泡**：默认跟随皮肤；关掉「跟随皮肤」后可以自己选颜色与不透明度。
- **助手气泡**：默认关闭。Aharou 的对话区是扁平的文档流——助手正文直接铺在页面上，没有气泡。打开这个开关后助手消息也会套上气泡，和你的消息对称。
- **圆角**：两种气泡共用一个圆角，拖动即时预览。

气泡里的文字颜色会按底色自动取对比色，不用担心换成浅色底后文字糊掉。

## 自定义背景图

在「外观主题」面板的下方可以设一张全局背景图：

- **选择图片**：从系统相册选一张作为 App 全局背景，叠在所有页面内容上（水印效果，不拦截触摸）。终端页保持纯黑底，不显示背景。
- **透明度**：滑块显示 0% 到 100%，实际生效范围映射到 0% 到 20%（也就是滑到 100% 相当于 20% 不透明度），这样保证文字始终可读。默认 15%，拖动实时生效。
- **移除背景**：恢复默认纯色背景。

背景图文件保存在应用私有目录，**不随备份导出**，换设备需要重新设置。

## 终端外观

终端的配色主题、字体、字号、光标样式是单独一套设置，见[终端](/guide/terminal#外观设置)。

代码编辑器的语法高亮、Git 泳道色、日志级别色与 diff 增删红绿也都各自独立，不随皮肤改——它们是功能标识，含义要在任何皮肤下都一致。
