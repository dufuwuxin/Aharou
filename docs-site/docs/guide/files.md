# 文件浏览与代码编辑

::: tip 版本说明
文件树与代码编辑页从 v1.11.0-dev 起提供。
:::

侧边栏顶部的「文件」标签页用来浏览当前工作区与当前容器的文件，点文件默认打开全屏的代码编辑页（图片与安装包除外，见下文「图片与安装包」）。文件浏览与编辑仅作用于本地工作区和本地容器。

## 浏览文件

「文件」页是一棵就地展开的缩进文件树，有**两个根**：

- **`workspace`**：当前工作区，默认展开。
- **当前容器**：名称就是当前选中的容器（如「内置 Alpine」），图标与设置里的「容器与镜像」列表一致。展开后是容器的整个文件系统（`/etc`、`/root`、`/usr` 等），默认折叠。本地 PRoot 容器里看到的是容器内的文件。

两个根各自能折叠展开，右上角还有一个刷新按钮。

- 点目录在原地展开或折叠，点文件直接打开编辑页（图片、安装包见下文「图片与安装包」）——不用一层层"进入下一级、返回上一级"。
- 目录排在文件前面，同类按名称排序。
- 文件按类型显示不同图标（代码、脚本、配置、文档、图片、音视频、压缩包等），采用与 App 全局一致的单色线性图标并跟随主题色着色。
- 着色规则类似 VS Code：`.` 开头的隐藏文件显示为浅色弱化，被工作区根 `.gitignore` 命中的条目显示为橙色（只看工作区根目录的 `.gitignore`，不解析子目录里的；容器里的文件不受影响）。
- 路径很深或文件名很长也不怕：整棵树共享一个横向滚动，名称不会截断成省略号，左右滑动就能看全。
- 你展开或折叠过的目录会**按工作区记住**，关掉 App 再打开、或者切走再切回同一个工作区，都会恢复上次的展开状态。
- 容器根只在展开时才去读目录；读不到时（例如本地容器还没装好）这一行会标红，工作区那棵照常显示。

## 搜索文件

「文件」页顶部（标签栏下方）有一个搜索框，和「会话」页那个长得一样。输入关键词后列表区就地换成搜索结果，**文件名和文件内容一起搜**：

- 结果按文件分组：组头是文件名加它所在的目录，右侧数字表示这个文件里命中了几处，点组头可以收起或展开。
- 只命中文件名的文件，点组头就直接打开；命中文件内容会逐行列在组里，点某一行会打开编辑页并**自动滚到那一行**。
- 关键词会高亮显示，顶部一行告诉你也一共命中多少个文件、多少处。
- 命中太多时只显示前面一批，顶部会提示「结果过多，仅显示前 … 条」，把关键词写具体一点就能收窄。
- 容器里的搜索遵守工作区的 `.gitignore`，被忽略的目录与文件不会出现在结果里。容器还没初始化、或容器里没装 `rg` 时会改用应用内自己遍历——能搜到，但大工作区会慢一些。
- 每个文件默认显示前 10 条内容命中；点击组内的「再显示 … 条」会再展开最多 10 条，直到显示完这个文件已有的搜索结果。修改关键词或搜索结果更新后，展开范围会重置。组内展开不会获取新的结果，也不会绕过顶部提示的搜索总量上限。
- 点搜索框右侧的 × 或把内容删空，就回到原来的文件树。

## 图片与安装包

文件树里的**图片**（png / jpg / jpeg / gif / webp / bmp）点开是应用内的全屏查看器，可以捏合缩放、双击放大，与聊天区看图一致；**APK / APKS / XAPK** 点开直接调系统安装器（首次会引导你开启「允许安装未知应用」）。这两类都不会进入代码编辑器，其余文件仍照常打开编辑页。

### 授权离线分析

要静态分析自己有权检查的二进制或安装包，可在容器终端的 `aicode → 环境安装` 选择「授权离线逆向分析」，补装基础工具，并按需选择 `jadx` / `apktool`，详见[离线分析环境](/guide/tools#安装离线分析环境)。安装场景不会打开或执行样本，也不会改变点开 APK 时调用系统安装器的既有行为；查看未知安装包时不要把点击安装当作静态分析。

## 从对话里点开文件

AI 在对话中引用代码时会把路径写成可点击的链接（带下划线的 `文件路径:行号`）。点这类链接会直接打开编辑页，带行号的还会自动滚动到那一行，并让它**尽量停在屏幕中间**（目标行靠文件开头或末尾时受滚动范围所限会贴边）。打开后你一滑动，自动定位就交还给你，不会再把画面拽回目标行。

支持工作区内的文件。AI 配置目录（`~/.aharou/...`）与容器系统文件（`/etc/...`、`/root/...`）指向本地容器内的私有目录与 rootfs。指向普通网址的链接不受影响，仍然用系统浏览器打开。

点到不存在的路径、目录，或超过大小上限的文件时，编辑页会给出对应的失败提示。

## 列表刷新

本地工作区下文件变动会**自动刷新**，不限于 AI 改的——你在终端里跑命令、或者用别的 App 改动同样会被感知。

它监听的是工作区根、容器根（展开时）和当前所有**已展开**的目录，不递归整棵树，所以大仓库下也不会吃掉大量系统资源；折叠某个目录后就不再监听它。

另外两个刷新时机：侧边栏每次出现都会重读一次（宽屏常驻侧栏下，每次从其它页面回到聊天页也算）；文件树右上角的刷新按钮可以随时手动重读。

发现文件列表与实际状态不符时，可点刷新按钮重新读取。

## 新建、重命名、删除

**长按目录行**（工作区根、容器根或任意子目录），从底部菜单里选「新建文件」或「新建文件夹」，新建的条目落在该目录下。如果长按的是折叠状态的目录，会先自动展开好让你看到结果。

名称只能是单个条目名：含 `/`、`\` 或者是 `.`、`..` 时确认按钮点不动——避免一不小心创建到别的目录去。同名条目已存在或目录不可写时会提示失败，不会覆盖原有文件。

**长按文件或子目录行**可以重命名和删除，也能**复制 / 剪切**，剪切板非空时目录行上还会多出**「粘贴到此处」**——跨目录搬运就靠这三步（两个根节点都只能新建）：

- **重命名**：只在同一目录内改名，不做跨目录移动。
- **删除**：文件直接删除；文件夹会连同里面全部内容递归删除，所以会先弹确认框。

**「加入输入栏」**：长按文件或子目录行选它，就把这个条目作为附件放进聊天输入栏的待发列表，接着补一句说明就能发送。**文件夹不会被打包**，投递的是一个指向该目录的路径引用——AI 拿到路径后自己按需读取里面的文件。所以目录多大都不用等打包，也不会额外占用磁盘；发送后可以在消息的附件行里看到完整路径。

复制或剪切后，文件树右上角（刷新按钮旁）会出现剪贴板图标提示当前状态，点它可以清空。

目标已存在同名条目时会先询问是否覆盖，覆盖会替换原有条目及其内容，不可撤销。也不能在原目录用粘贴覆盖源条目，或把文件夹复制 / 移动到自身及其子目录——这类操作会被拒绝，源文件保持不变。

::: danger 删除不可撤销
删除不进回收站，也不受检查点保护。确认前想清楚，尤其是删文件夹。
:::

## 代码编辑页

人工编辑与 AI 成员分别保留各自读到的版本，不需要争用编辑页面。仅打开文件不会改变 AI 成员的读取记录；用户保存后，仍持旧内容的成员必须重新读取再修改。编辑器保存与 AI 文件工具共享同一路径的写入事务：先检查冲突，再写入；强制覆盖也会等待正在进行的文件事务，但不会丢掉其他标签的草稿。不同工作区的同名文件分别保存标签、草稿与读取基线。终端命令或其他进程不受此进程内互斥保护，仍需依靠保存前的内容检查发现冲突。

保存失败（含远程断线或服务器拒绝写入）会保留未保存状态，不显示“已保存”。打开文件时，冲突基线直接取自实际读到的同一份字节；外部修改不会被当成编辑器已经看过的版本。保存期间继续编辑或切换标签，较晚草稿仍保留；恢复草稿后撤销也不会把它误判成已落盘。

文件事务绑定到对应的工作区，不会因全局选中目录改变而串用。

点文件后侧边栏收起，进入全屏编辑页。

顶部左上是返回，右上有查找、撤销、重做、保存、设置。工具栏空间不足时可横向滑动查看其余按钮。撤销和重做在没有可操作内容时置灰，保存按钮只在有未保存改动时可点。

- **撤销按输入停顿分步**：连续快速输入算一步，停顿约半秒后再输入就算新的一步。一路撤销回打开时的样子后，文件名前的星号消失、保存按钮置灰，此时退出也不会再问你要不要保存。
- 打开 Markdown 文件时，撤销按钮左边会多一个**预览切换**按钮，点一下切到渲染效果，再点切回源码。预览和源码共用同一编辑状态，切换不会丢失未保存的修改。
- 预览是完整的 Markdown 渲染：**文档里内嵌的 HTML（居中标题、图片、表格排版、徽章等）会照常显示**，代码块带语法高亮，配色跟随应用深浅主题。文档里的相对路径图片（如 `docs/a.png`）会从当前工作区读取；网络图片（徽章、在线图表等）需要联网才能加载。预览页内点击链接不会跳转，避免离开当前文档。
- 预览不含 LaTeX 公式渲染，含公式的文档切回源码查看。
- 导航栏下面有一条文件名小栏：左边是文件名（有未保存改动时前面加星号），右边是光标的行列位置和文件编码。
- **底部快捷符号栏**可横向滚动，最左是光标左右移动和缩进（Tab），后面是编程常用符号（括号、引号、运算符、`;` `:` `|` `&` 等），点一下就在光标处插入。软键盘弹出时符号栏会浮在键盘上方。
- **选中代码后**，长按弹出的工具条上会多一个**「加入输入栏」**：把选中的片段存成工作区 `.aharou/attachments/` 下的一个文本文件，并作为附件放进聊天输入栏，接着补一句说明就能发送。同一个文件选两次会存成两个文件，不会互相覆盖。
- 有未保存改动时，点返回或按系统返回键会先弹确认框，可以选「不保存」或「保存并退出」。
- **滚到文件末尾还能再上滑半屏**：最后几行不会紧贴屏幕底边，方便在文件结尾处编辑。

### 查找当前文件

点击工具栏的放大镜，在查找框输入关键词。查找的是当前编辑内容，**包括尚未保存的修改**，不区分大小写，按普通文本匹配，空格也会参与匹配。

搜索完成后会选中一个匹配并显示「当前序号 / 总数」。点击上、下箭头或键盘的搜索键可跳转，越过首尾后会循环。移动光标到匹配之外时当前序号显示为 0；没有匹配时显示「无匹配结果」，导航按钮置灰。编辑文本后，查找结果会自动更新。

点击查找框旁的 × 或按返回键关闭查找，会清除高亮与查询，不会修改文本、未保存标记或撤销记录。切换文件、进入 Markdown 预览或离开编辑页时也会清理查找；预览中不能启动查找，切回源码后再点放大镜即可。

### 语法高亮

内置了这些语言：Kotlin、Java、Python、JavaScript/JSX、TypeScript/TSX、JSON/JSONC、YAML、Shell、Go、Rust、C/C++、CSS、XML、HTML、Markdown、PHP、Lua。`.kts` 按 Kotlin 高亮。未识别的类型按纯文本显示，不影响编辑。

配色用的是 VS Code 默认主题（深色 Dark+ / 浅色 Light+），随应用主题自动切换，编辑过程中切主题不会丢失未保存的内容。

### 编辑器设置

点右上角设置按钮进入独立的设置页，改动即时生效并记住，下次打开沿用：

- **字体大小**：滑块调节。
- **自动换行**：开启后长行折行显示，不再横向滚动。
- **显示缩进参考线**：默认开启。
- **显示自动换行箭头**：自动换行开启时在折行处画指示箭头，默认关闭。
- **显示空白符号**：把空格、Tab、换行可视化，默认关闭。
- **行尾显示诊断提示**：在报错行的行尾直接写出诊断文字，不必悬停看气泡（即 Error Lens），默认开启。注意它只对**轻量语法检查**产生的诊断生效；语言服务器的诊断仍只在波浪线气泡里显示。

### 代码诊断与语言扩展

编辑器会像 IDE 那样把问题直接标出来：**错误是红色波浪线、警告是黄色波浪线**，点一下能看到具体信息。诊断有两条来源：

- **轻量语法检查（无需安装）**：打开或保存文件时，在容器里对当前文件跑一次语法检查，目前覆盖 Python（`python3`）与 Lua（`luac`）。容器没初始化、检查器没装、文件超过 512KB 时一律安静跳过，不影响正常编辑；检查的是**磁盘上的文件**，未保存的改动不会立刻反映。
- **语言服务器（LSP）**：Lua、Python、TypeScript/JavaScript、Shell/Bash、YAML、Vue 与 Rust 使用校验过的预编译扩展包，在「编辑器设置 → 语言扩展」中主动安装。安装目标是当前默认后端，服务器按工作区绑定后端启动；请将默认安装后端与目标工作区绑定保持一致。扩展包要求 ARM64 Ubuntu 24.04。安装时先准备 rootfs 或 SSH 连接，再检查并按需补齐固定运行时包；Node 扩展自带私有 Node 24.22.2，不替换已有 Node 或 Rust 工具链。远端缺运行时且无 root 权限时显示明确错误，不自动 sudo。切换工作区、容器或连接配置会关闭旧语言服务。不要在不可信 Rust 工程中执行构建或宏；PRoot 并非恶意代码隔离沙箱。

> `.vue` 文件的高亮目前复用打包好的 HTML 语法：`<template>` 与 `<style>` 能正常上色，`<script>` 里只有 JavaScript 有嵌套高亮，TypeScript 写法暂时按普通文本处理。

两条路都在「打开 / 保存」时触发；两者都没有时（比如还没装 Lua 服务器、或文件类型不在覆盖范围）就是静静地不标，不会弹错。

### 保存与并发

保存是**整份覆盖写回**，成功后提示「已保存」。

::: warning 不做外部并发检测
AI 工具或终端可能同时在改同一个文件，而保存会直接用编辑器里的内容覆盖，不会提示文件已被外部改动。如果你和 AI 可能同时动同一个文件，先让一方改完再动手，避免互相覆盖。
:::

### 换行符（LF 与 CRLF）

Windows 上编辑过的文件常用 CRLF（`\r\n`）换行，Linux / macOS 风格是 LF（`\n`）。编辑器按文件原有的换行显示和保存，不会在保存时悄悄把整份文件统一成 LF。

让 AI 改这类文件时也不需要自己先转格式：AI 读到的内容换行是 LF，所以它可以按 LF 书写要替换的原文，即使磁盘上是 CRLF 也能正确匹配并应用。写入时，被替换进去的内容沿用该位置的原有换行格式，**没改到的区域换行保持原样**——一次局部修改不会把整份 CRLF 文件变成 LF。

只有整份重写文件或新建文件时，换行才以 AI 给出的内容为准。

### 限制

- **文件大小上限 2 MB**。超过的不打开——内容需要整份读进内存，再大会明显卡顿甚至崩溃。
- **不支持二进制文件**。打开时会嗅探文件开头，识别为二进制（图片、可执行文件、压缩包等）会直接提示，不会把乱码当文本载入。

## 工作区文件在手机上的位置

「文件」页浏览的是工作区内容，而工作区文件、AI 配置都存放在应用私有目录里，普通文件管理器默认看不到。想用外部工具打开或备份时，有几种办法：

**文件管理器挂载（推荐）**：App 实现了标准的 DocumentsProvider，用手机自带的「文件」管理器或第三方文件管理器（MT 管理器、Solid Explorer 等）可以找到并挂载 App 的私有根目录。挂载后能看到：

- `projects/`：工作区项目。通过「添加外部工作区」加进来的外部工作区不在这里，它们在你自己选的设备目录下。
- `aharou/`：对应容器内的 `~/.aharou`，里面有 `skills/`（技能）、`docs/`（文档）、`mcp.json`（MCP 配置）等。
- `shared/`：跨工作区共享区，对应容器内的 `~/shared`（见〈容器与镜像〉）；里面的 `inbox/` 是跨工作区信箱，每个工作区一个文件，`inbox/workspaces.md` 是自动维护的工作区通讯录（各工作区的信箱地址）。

以 MT 管理器为例的挂载步骤：打开 MT 管理器 → 点左上角菜单（三横线）→ 侧边栏右上角的三个点 → 「添加本地存储」→ 系统文件选择器打开后点左上角三个点、选「Aharou」→ 点底部「使用此文件夹」。

**内置终端**：切到终端页，`cd ~/.aharou` 直接看，用 `vi` 或 `cat` 查看编辑。

**直接让 AI 做**：AI 就跑在容器里，你可以说“把 `~/.aharou/mcp.json` 打印出来看看”或者“在 `~/.aharou/skills/` 下写一个新技能”。

**Root 设备**：直接进 `/data/data/com.aharou.agent/files/`（部分系统等价路径是 `/data/user/0/com.aharou.agent/files/`）。其中 `projects/` 是工作区根，`aharou/` 对应 `~/.aharou`，`aharou-global/shared/` 对应 `~/shared`，`rootfs/` 是容器系统。注意 debug 构建的包名是 `com.aharou.agent.debug`，两者私有目录完全隔离。

### 扩展安装与编辑状态

点击语言扩展“安装”会在安装锁内初始化当前默认容器或连接 SSH，确认 ARM64 Ubuntu 24.04，并仅在缺依赖时安装 python3.12、libstdc++6、libatomic1、ca-certificates，再下载并校验扩展包；不修改 apt 源，不安装或升级全局 Node。页面只读检查不初始化容器、不安装依赖。后端中途切换会中止后续安装。失败显示具体原因并可重试，取消会释放安装状态。预编译语言扩展需要 ARM64 Ubuntu 24.04 后端。未修改文件的编辑快照只保留光标和滚动位置；未保存的草稿继续保留完整正文。

### 人工编辑与成员协作

代码编辑器用于人工审阅、选择代码、修改和保存草稿，以及查看诊断；成员通过文件工具直接改代码，不需要轮流占用屏幕。编辑器和文件工具共用路径锁，保存时在锁内比较磁盘版本；对方已修改时保留草稿并提示冲突，不静默覆盖。打开文件不会把成员的旧读取记录刷新成“读过新版本”。标签和未保存草稿按工作区隔离。终端和外部进程不受应用内路径锁约束，其内容变化仍会在保存前进行指纹比较。
