# 终端

Aharou 内置一个完整的终端。本地模式下它连着手机上的 Linux 容器，远程模式下它连着你的 SSH 服务器——两种情况都是真实的 shell，可以装包、编译、跑服务。

从聊天页顶部标题栏的「终端」进入。点左上角返回按钮回到聊天页，返回过程中重复点击不会继续退出聊天页。返回不会关闭终端标签。

## 环境与内置资料更新

本地 Linux 容器和远程 SSH 都保留。启动及进入终端时，内置资料内容未变就不重写；升级产生的旧文档路径会在新文档写入成功后清理。自定义提示词、已编辑的成员与团队定义不会被内置默认文件覆盖。

远程连接首次就绪或重连后会同步内置资料；多个入口同时触发时合并处理，未完成的阶段会在后续命令中重试。共享区仍随每条远程命令回拉，同一条命令不会重复回拉；关闭连接前也会尝试带回远端修改。

## 标签管理

终端支持多个标签同时存在，顶部标签栏可以横向滑动，切换时当前标签会自动滚动到可见位置。

- 标签名前的圆点表示状态：绿色是运行中，灰色是已结束。
- 点标签右侧的 × 关闭，点标签栏末尾的 + 新建。关掉当前标签后会自动切到相邻的一个。
- AI 执行命令时开的终端也会出现在这里，你可以随时切过去看它在干什么。

## 后台命令与输出预览

AI 发起的后台命令支持多行脚本和 here-document，不必为了退出提示改写成单行。命令的退出码标记与正文独立成行，即使程序最后没有输出换行，也不会把失败误当成仍在运行或成功。后台完成兜底只接受本次执行独有的回执；程序打印普通“退出码 0”文字不会提前结束任务，回执滚出缓冲后也不会把已确认的非零码改成 0。远程 shell 关闭却没有有效命令回执时保持未知退出状态（-1），不伪造成功。

聊天里的长输出可能只显示预览；这不等于命令不支持，也不等于执行失败。工具结果提供了完整输出路径时，应按路径分段读取，不要为了取日志重复执行命令。终端滚动缓冲本身有限，长任务建议预先保存日志；没有完整日志时，不能把屏幕上的尾部内容当成全部输出。

专用文件搜索工具不是通用 Shell，遇到不支持的复杂管道时应改用终端或命令工具，不要把参数校验失败与输出裁剪混为一谈。

## 输入与复制

点一下终端区域获得焦点，就可以直接输入。长按可以选择并复制输出内容。

## 辅助按键栏

手机键盘没有 Esc、Ctrl 和方向键，所以终端底部提供了一条可横向滑动的辅助按键栏：

- **控制键**：`ESC`、`TAB`、`CTRL`、`ALT`。Ctrl 和 Alt 按下后会高亮，再按字母键即组成组合键。
- **方向键**：上下左右，长按可以连续发送，用来快速移动光标。
- **常用组合**：`C-c` 中断当前命令、`C-d` 发送 EOF 或退出、`C-z` 挂起进程、`C-l` 清屏。
- **常用符号**：`|`、`~`、`/`、`-`、`_`、`>`、`:`、`$`、`"`、`'` 等，省去切换符号键盘。

## 外观设置

点终端页右上角的齿轮图标（或者从「设置 → 终端设置」进入）可以调整：

- **配色主题**：内置 Termius Dark、Dracula、One Dark、Monokai、GitHub Dark 五套配色，选中立即生效，所有已打开的标签一起变。
- **字体大小**：5 到 22 之间无级调节，面板顶部有实时预览；也可以直接在终端区域双指捏合缩放，和这里的取值是同一个。
- **字体**（**v1.11.0-dev 起**）：默认是 JetBrains Mono（无连字版本），`0` 和 `O`、`1` 和 `l` 区分得很清楚。也可以切换成系统等宽字体，或者点「导入」从手机里选一个 `ttf` / `otf` / `ttc` 字体文件；导入的字体会出现在列表里，点字体标签上的 × 可以删除，删掉正在用的会自动回落到系统等宽。中文字符始终由系统字体补齐。字体只影响终端，不改变 AI 对话区。
- **光标样式**：方块、下划线、竖线三种。
