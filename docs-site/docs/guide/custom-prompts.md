# 行为要求与每轮背景

日常行为要求与背景在[记忆库](/guide/memory)中管理，不需要维护独立提示片段或额外来源开关。

## 选择合适的类别

- 要求助手遵守的表达方式、交付标准与工作约定，放在**规则类**。
- 每轮都需要的项目背景、偏好与助手设定，放在**注入类**。
- 只属于当前对话的材料，放在**临时存放类**并绑定目标对话。
- 仅在相关任务中查阅的事实和经验，放在**长期类**。

## 检查实际使用

打开条目，确认使用方式是正文常驻、摘要索引、仅检索或停用。类别和文件夹不能代替使用方式；正文常驻仍受单条与总预算限制。

在「注入预览」输入当前任务并选择目标对话，核对哪些内容进入正文、哪些只提供摘要，以及未带入的原因。保存成功不等于当前请求已经加载，预览也不是历史请求记录。

## 应用运行机制

内置系统提示、技能流程、工具定义与按需场景模板仍由应用各自的消费者使用，不作为记忆库的用户条目。项目指引仍按项目机制生效；记忆正文不能扩张工具权限。

只在一个条目维护同一要求。修改已有内容前核对最新版本，发生冲突时保留草稿并重新读取，不创建多份互相矛盾的副本。
