# 功能总览

本页作为使用手册的快速导览索引，整理了主界面核心工作流与设置页各功能入口对应的文档。

本索引按**功能主题**归组，不代表设置页里的实际分组。底栏「配置」集中提供 AI 供应商、默认与专用模型、插件、连接器、凭据库，以及记忆、技能、团队、工具、自动化任务、提示词和规则；这些 AI 配置不在通用设置里重复展示。

设置页保留账号中心、人格、配置审计，以及通用偏好、运行环境、权限、后台、存储与诊断等入口。「自动化任务」可从「配置」直接进入，也保留工具页内的原入口；两处管理的是同一份任务。MCP 服务器统一在「配置 → 工具」管理，连接器中关闭服务器配置弹窗、或从服务器日志返回时回到打开连接器前的页面：从配置进入就回配置，从工具页进入就回工具页。帮助与关于、连接与同步已移除。

::: tip 版本说明
标了版本的条目（如「v1.11.0-dev 起」）表示该功能自该版本起引入。
:::

## 项目对话与工作树

点击「创建项目」，只需填写项目名称和「项目存在的意义」。创建会先保存一个独立工作区中的空项目，不调用 AI，也不自动生成或执行任务；没有配置 AI 供应商也能创建。创建期间显示进度且不能重复提交，成功后立即出现在列表并进入项目；如果你已经切换到其它项目或工作区，则不打断当前页面，可稍后从列表打开。失败时保留输入，可直接重试，不会清理已有的同名项目。

创建后，在项目底部的对话输入栏告诉 AI 具体需求，也可以继续追加或修改需求，沿用现有任务规划与修订流程。项目意义作为独立背景保留，不会被当成待执行需求；旧项目原有需求仍可查看。使用 AI 规划和执行前，仍需配置可用模型。

首次打开或点击桌面图标进入项目工作台；如果已在项目首页，会保留当前页面和正在填写的创建表单，不重复切换首页。划词、小组件指定会话、新建入口与文件分享仍按各自用途处理，不被首次引导切走。项目任务按已选成员执行，不需要再填写团队名称；停止项目会停止当前运行成员，后续任务保留。

项目会话保留原聊天顶栏与完整输入功能，只将消息区改为任务树／思维导图。底部半透明胶囊点击后展开原输入栏，可添加图片、拍照、上传文件、选择模型与 Build／Plan／Auto／Allow 模式，并保留排队、插话和停止。终端、Git、浏览器、本地文件与共享目录仍从聊天顶栏进入。

直接在输入框说明需求，由 AI 判断补充现有任务还是新增任务；也可展开任务节点，点击「添加子任务」继续分化为三级、四级任务，新任务固定放在所选节点下。项目工作台保留「添加任务」入口。思维导图支持「适配全图」、双指缩放和继续缩小查看概览，放大后操作具体节点。隐藏输入法或拖动树图时底栏收起，草稿和附件保留；模型和附件弹窗不会因收起被销毁。点击项目根节点展开该项目的 AI 回复、澄清、失败记录及实时输出；成员记录在任务节点内只读展开，不改变底栏所绑定的项目根会话。成果验收入口保留，仍要求验收条件、证据和当前有效交付；未归属项目的旧会话继续显示消息列表。绑定失败时保留树图但禁用输入，返回重进可重试。

配置页不再提供个人中心；助手形象与配置审计入口保留。已有聊天昵称和头像不会因移除该页面而清空。

工具、记忆、提示词和规则集中在底栏「配置」，不在设置页重复展示。自动化任务只从「配置 → 工具 → 自动化任务」管理。

配置首页提供「离线英译中」：专用英中语言包约 119.5 MB，由应用内下载、校验并安装，不调用系统下载器或外部浏览器。技能、角色、记忆库内容编辑及项目需求提供「英译中」按钮，只显示译文，不覆盖原文。打开页面不会自动下载语言包；已安装后可离线推理。语音识别、通话、唤醒、朗读与默认语音助理已移除；桌宠文字提示、媒体控制、音视频附件、Shizuku 和无障碍保留。
