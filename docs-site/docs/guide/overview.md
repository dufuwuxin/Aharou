# 功能总览

本页作为使用手册的快速导览索引，整理了主界面核心工作流与设置页各功能入口对应的文档。

本索引按**功能主题**归组，不代表设置页里的实际分组。底栏「配置」集中提供 AI 供应商、默认与专用模型、插件、连接器、凭据库，以及记忆、技能、团队、工具、自动化任务、提示词、规则和四种机器人接入；这些 AI 配置不在通用设置里重复展示。

设置页保留账号中心、人格、配置审计，以及通用偏好、运行环境、权限、后台、存储与诊断等入口。「自动化任务」可从「配置」直接进入，也保留工具页内的原入口；两处管理的是同一份任务。MCP 服务器统一在「配置 → 工具」管理，连接器中关闭服务器配置弹窗、或从服务器日志返回时回到打开连接器前的页面：从配置进入就回配置，从工具页进入就回工具页。帮助与关于、连接与同步已移除。

::: tip 版本说明
标了版本的条目（如「v1.11.0-dev 起」）表示该功能自该版本起引入。
:::

## 项目对话与工作树

项目会话保留原聊天顶栏与完整输入功能，只将消息区改为任务树／思维导图。底部半透明胶囊点击后展开原输入栏，可添加图片、拍照、上传文件、选择模型与 Build／Plan／Auto／Allow 模式，并保留排队、插话和停止。终端、Git、浏览器、本地文件与共享目录仍从聊天顶栏进入。

直接在输入框说明需求，由 AI 判断补充现有任务还是新增任务；不再提供节点长按添加／补充或手动编辑弹窗。隐藏输入法或拖动树图时底栏收起，草稿和附件保留；模型和附件弹窗不会因收起被销毁。点击项目根节点展开该项目的 AI 回复、澄清、失败记录及实时输出；成员记录在任务节点内只读展开，不改变底栏所绑定的项目根会话。成果验收入口保留，仍要求验收条件、证据和当前有效交付；未归属项目的旧会话继续显示消息列表。绑定失败时保留树图但禁用输入，返回重进可重试。

| 依赖版本检查 | 让 AI 检查 Gradle 依赖是否有新版本，并给出「改哪一行、从什么改成什么」的建议 → [文档](/guide/dependency-check) |
