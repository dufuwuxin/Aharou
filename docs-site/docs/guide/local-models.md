# 本地模型（离线推理）

本地模型在设备上执行推理，不需要把对话发送给云端模型服务。首次使用仍需联网下载权重；模型文件不随安装包分发。

## 下载与选择

1. 打开设置中的「默认模型」，找到「本地模型（离线推理）」分区。
2. 选择合适的模型，点击下载。下载完成后会进行完整性校验，校验通过才可使用。
3. 如果下载中断，可再次点击下载续传；校验失败时按界面提示重试。请预留足够的存储空间，下载和校验期间不要清理模型文件。

本地推理要求设备使用 **arm64-v8a**；设置页会提示不支持的设备。文件可下载不等于在每台设备上均能成功加载或流畅推理。

7B 使用的是官方**单文件 Q3_K_M**，不是 Q4_K_M。官方 7B Q4_K_M 分为两个文件，当前下载流程只管理单文件模型，因此未把它列入可下载目录。量化档位不同，不能仅按参数量推断回答质量。

新增模型沿用现有推理库，不引入新的推理引擎；本次也没有加入 Qwen3，不能把目录扩展理解为已经验证了新架构兼容性。

## 来源与校验

新增模型的下载地址来自 Qwen 官方 ModelScope 仓库。2026-11-12 已核对公开文件元数据中的实际字节数与 SHA-256；下载器按目录记录校验文件，文件大小相同不能代替哈希校验。

- [Qwen2.5 3B Instruct GGUF](https://modelscope.cn/models/Qwen/Qwen2.5-3B-Instruct-GGUF)
- [Qwen2.5 7B Instruct GGUF](https://modelscope.cn/models/Qwen/Qwen2.5-7B-Instruct-GGUF)

若上游替换了文件而本地校验未通过，请保留错误信息并反馈，不要通过关闭校验或把其他量化文件改名来绕过。内存不足、加载失败或推理很慢时，优先尝试原有小模型并关闭其他占内存应用；内存提示不是支持承诺。

## 从文件导入与加载校验

在「配置 → 默认模型 → 本地模型」中，选择对应型号的「导入已校验的 GGUF 文件」，再通过系统文件选择器选取文件。导入只接受该目录型号对应的 GGUF、字节数和 SHA-256；不是任意同名文件，也不代表支持 MNN 或 ONNX。取消选择不修改模型；格式、大小或校验失败会保留原文件，成功后才原子替换。

实际加载到推理库前会再次检查格式、大小和哈希，避免重启后仅凭大小将损坏权重交给 JNI。文件在本地通过完整性检查，不等于已在当前设备测过速度、内存或生成质量。当前仍使用已有 llama.cpp 后端；设备架构限制和各型号提示保持不变。
