# 凭据库

## 安全与隐私脱敏

在「设置 → 凭据库」打开「额外隐私脱敏」，工具结果、日志与审计会额外识别常见认证字段、密钥格式、私钥块、邮箱与大陆手机号。默认关闭；原有凭据库值的脱敏不受此开关影响。设置保存后立即作用于后续结果，不重写历史日志。

同页提供最多 8192 字符的本地预览，不保存输入、不联网。预览始终启用额外识别；可以长按复制脱敏结果，确认后再自行发送。格式匹配不能保证发现所有隐私，请检查结果。

此功能不向安全术语插入不可见字符，不修改原文件、登录认证请求或你手动发送的消息；明确批准读取的敏感结果继续按原授权处理。对应配置项为 `vault.privacy_redaction`。


「设置 → 凭据库」是本机的**密钥保险箱**：把 API Key、令牌这类敏感值集中存在一处，供连接器等需要密钥的功能引用，而**不把明文写进各自的配置文件**。

## 存的是什么

每条凭据有**名称**和**值**两部分：

- **名称**只能是字母、数字、下划线、点和短横线，不能重名。它是引用这条凭据时的「键」。
- **值**保存时即加密（密钥托管在 Android Keystore、与设备绑定），列表里**只显示名称**，不回显明文。

## 列表与占位符

每个凭据行只显示两项：**名称**，以及它的**占位符** <code v-pre>{{vault:名称}}</code>。

占位符就是给 AI 和其它配置引用的写法：AI 只能看到这个占位符、看不到真值；真值只在使用它的地方（例如某个连接器建立连接时）由本机还原。这样即使 AI 读到了配置或日志，也拿不到密钥本身。

## 添加与删除

- **添加**：点列表下方的「添加」，填名称与值，保存。名称为空、格式不合规或与已有重名都会当场提示。
- **删除**：点凭据行右侧的垃圾桶图标，确认后删除。删除后引用它的地方会失效。

## 出错怎么办

- **换设备或清除数据后旧值失效**：凭据与设备绑定，换机或清数据后旧密文解不开，需要重新录入。
- **引用的凭据找不到**：检查名称是否写对（区分大小写、注意点与短横线），或这条凭据是否已被删除。
