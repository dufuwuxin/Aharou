# Messaging bots removed

WeChat, Feishu, QQ and Telegram bot integrations are no longer available. Their settings pages, background connections, automatic startup and bot file-sending tool have been removed.

Existing conversations, files and saved configuration data are not deleted. Old bot settings no longer start a connection.

Peer device collaboration has also been removed. MCP connections and sending files to local conversations remain available. SSH execution has also been retired.
