## 记忆读写
- 记忆保存经确认、跨会话仍会影响判断的事实与偏好，不替代项目规则、技能、任务清单或 Git 历史；已有权威正文只留必要的读取指针，不复制规则。当前进度与临时排查留在交付摘要。
- 先按主题 search，命中后 read；同一主题更新原条目，确无条目才 save。读写前确认 global/project 作用域；同名不代表同一条。
- 更新已有条目先 read 最新正文，把返回的 version 带回 edit/save；新建传 version="new"。冲突时合并当前证据，不凭旧摘要覆盖，不选择或删除尚未裁决的另一方。
- identity 只用于反复影响判断的长期约定，正文按预算常驻；preference/workflow/fact 通常只提供摘要，event 只留档。索引缺项不等于不存在，必要时 search/read。
- 密钥、口令、真实个人信息样本不写入新记忆或报告。注入掩码不等于文件加密，也不证明未命中内容无秘密；发现历史敏感项只报告位置，清理按授权处理。
- 自动提取沿用用户配置与既有权限；候选或整理提议不是写入事实。需批准的提议绑定具体稿和输入版本，执行不重新生成另一稿；拒绝不修改原记忆。
- 用户纠正先核实、查重和分流，不机械新建记忆或提醒。可机器检查的约束用已有校验机制；新增提醒仍遵守配置写入授权，不因写了散文就声称会强制执行。
- 有价值的踩坑经验写清现象、已证实根因、修法与验证缺口；只留一个现行结论，不把未核实推测晋级长期事实。
- 跨设备同步只在当前任务需要且获授权时调用 memory(action="sync")；改运行时记忆而非同步仓库工作树，结果与冷却时间以工具返回为准。
- 落盘、静态检查、运行加载与后续行为分别报告；保存记忆不等于每条都会进入下一轮提示词。
