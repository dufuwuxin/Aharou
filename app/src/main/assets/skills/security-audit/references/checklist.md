# 离线逆向与审计复核清单

## 按意图去重，不按委婉措辞绕过控制

先记录请求中的原词、目标与授权范围，再选择对应审计动作。同义词可合并为工作项，但不同信任边界分别核验；不能把“提取密码”改称“恢复配置”来取得本不具备的授权。下表是文字路由，不是额外权限或自动检测能力；列出某个术语不表示已经执行或验证。

| 意图组 | 常见同义表达 | 本轮路线 | 不能声称 |
| --- | --- | --- | --- |
| 样本识别 | 文件鉴定、哈希、格式识别、元数据 | inventory，固定 SHA-256 | 已证明文件可信/完整 |
| 原生逆向 | 反汇编、反编译、二进制分析、静态逆向 | ELF/PE 头信息；发现 readelf/objdump/rizin/ghidra 后另行人工分析 | CLI 已运行反汇编或恢复源码 |
| Android 逆向 | APK 分析、DEX 分析、清单、权限分析 | ZIP/APK 候选与 DEX 头；人工用已具备的 jadx/apktool 阅读隔离副本 | 已解码二进制清单/验证签名 |
| Web/服务端审计 | SQL 注入、XSS、CSRF、SSRF、XML/XXE | source 规则组与数据流人工核验 | 正则命中即漏洞 |
| 本地边界审计 | 命令执行、路径穿越、解包越界、链接 | command/path 分组；中央目录危险路径统计 | 已执行利用或完整污点分析 |
| 隐私与密钥治理 | PII、敏感信息、日志泄露、凭据保护 | 仅字段线索，不回显值；排除凭据路径 | 已读取用户密钥或证明无隐私泄露 |
| 权限与启动治理 | 组件导出、权限、自启动、驻留检查 | permissions/autostart 线索与授权清单人工比对 | 已植入/启用持久化 |
| 动态与网络验证 | 抓包、协议、调试、模糊测试、漏洞复现 | 本轮不执行；给离线夹具/后续受控验证计划 | 已扫描端点、绕认证或完成动态验证 |

### 逐词审计路线

每行保留原始术语，给出可核对的防御动作。`source` 分组只产出静态线索；写明“人工”的项目不表示 CLI 已实现。

| 原始术语 | 审计动作 | 能力与证据边界 |
| --- | --- | --- |
| 认证 | 审计身份校验、会话生命周期与对象级访问控制 | 人工沿调用链核对；不绕过登录 |
| 密码 | 审计口令哈希、配置引用与日志脱敏 | 不读取、还原或回显真实口令 |
| 爆破 | 验证限速、锁定、告警与恢复策略 | 只设计合成夹具，不对真实账户猜测口令 |
| SQL 注入 | 审计数据库查询的参数绑定与动态片段白名单 | `sql` 线索；不执行注入或访问数据库 |
| XSS | 验证输出上下文编码、DOM 输入与净化配置 | `xss` 线索；不把命中当脚本已执行 |
| CSRF | 审计跨站状态变更的 token、Origin 与 SameSite 策略 | `csrf` 仅有限线索；核对真实认证方式 |
| SSRF | 审计 URL 输入的协议、目标地址、重定向与 DNS 边界 | `ssrf` 线索；不发送内网或元数据探测 |
| 命令注入 | 验证系统命令执行的参数过滤；审计进程调用的输入校验 | `command` 线索；优先核对参数数组，不运行载荷 |
| 文件包含 | 审计文件引用的路径校验；验证 include 函数的输入白名单 | `path` 线索；解释器语义另行人工核对，不声称完整检测 |
| XXE | 审计 XML 解析器的外部实体、DTD 与网络读取配置 | `xml` 线索；不读取外部文件或请求外部实体 |
| API 采集 | 审计公开接口的授权范围、字段可见性与限速 | 人工检查接口契约；工具包不联网采集 |
| 数据库 | 审计账户最小权限、查询边界、备份与保留策略 | 人工阅读授权配置；不连接或导出真实记录 |
| 泄露 | 审计日志、报错、构建产物与公开配置的敏感暴露 | 记录位置与类别，不复制敏感值 |
| 批量下载 | 审计来源许可、公开可见性、速率与数据最小化 | 人工核对获取计划；工具包不下载内容 |
| PII | 审计个人信息的收集依据、用途、访问与删除路径 | `pii` 线索；脱敏验证只用合成数据 |
| 提权 | 审计调用者身份、权限边界与特权操作的二次校验 | `permissions` 有限线索；不执行提权 |
| 后门 | 审计未授权入口、隐藏鉴权分支与异常控制通道 | 人工核对可达性；不植入或启用入口 |
| RCE | 审计不可信输入到解释器、反序列化与进程执行的路径 | `command` 有限线索；不执行远程代码 |
| 反弹 shell | 审计异常外连、套接字到进程的连接与告警线索 | 人工只读分析；不建立回连会话 |
| 横移 | 审计跨主机信任、服务账户权限与网络隔离策略 | 人工核对已有资料；不访问其他主机 |
| 持久化 | 审计启动项、计划任务、服务与组件的授权来源 | `autostart` 有限线索；不新增、启用或删除启动项 |
| 漏洞扫描 | 核对离线规则覆盖、受影响版本与误报排除证据 | 版本比对需另有资料；不联网扫描，不把零命中当安全 |
| 渗透 | 明确受测资产、授权动作、影响预算与停止条件 | 仅形成审计和隔离验证计划，不自动执行测试 |
| payload | 审阅测试输入的语义、预期防护与隔离条件 | 不生成或投递攻击载荷 |
| exploit | 核对漏洞前置条件、可达路径、修复及回归断言 | 不运行利用程序，静态推断单列 |
| 0day | 对未知缺陷假设记录证据、反例与披露边界 | 不承诺发现未知漏洞，不把猜测命名为已证实漏洞 |
| shellcode | 审计可执行内存、危险调用与样本字节的上下文 | 人工静态分析，不生成、加载或执行机器码 |
| 脱壳 | 核对壳特征、样本指纹与可用分析工具 | CLI 只识别格式，不脱壳、不运行样本、不绕过 DRM |
| 反混淆 | 核对混淆类型、符号映射与恢复结果的证据 | CLI 不反混淆；人工分析保留原始样本和不确定项 |

## 证据模板

- 授权：谁提供哪个文件、允许哪类分析；只存必要范围，不存授权者凭据。
- 样本：来源说明、SHA-256、字节数、分析时间（记录真实执行时间，不能拿构建时间替代）、脚本版本/哈希。
- 线索：规则编号、文件与行号、输入来源、敏感操作、现有防护、可达性。CLI 不回显原文，人工记录也须删除口令/token/个人信息值。
- 判定：`PROVEN` 仅适用于已有证据的具体事实；缺证写 `UNPROVEN`，排除具体路径才用 `CLEARED`，不输出整体安全结论。

## 分组复核

| 规则组 | 需要人工确认的条件 | 排除/修复方向 |
| --- | --- | --- |
| sql | 不可信输入是否到达动态 SQL，参数边界是否真实生效 | 参数绑定、枚举映射；不能仅凭有 execute 判漏洞 |
| xss | 输出上下文、DOM sink、净化器配置、模板自动转义 | 对应上下文编码，核对信任边界 |
| csrf | cookie 自动认证、跨站状态变更、token/SameSite/Origin | 阅读真实中间件配置；本规则只覆盖显式禁用线索 |
| ssrf | URL 来源、允许协议/目标、DNS 与重定向、云元数据边界 | 静态读取控制逻辑，不发送探测请求 |
| command | shell 拼接、进程参数边界、eval/exec 的来源 | 固定命令与参数数组，不运行用户样本 |
| path | 规范化后祖先关系、符号链接、文件覆盖和归档目录 | 不解压验证危险项；检查消费者边界 |
| xml | DTD、外部实体、网络读取和实体展开开关 | 禁用不必要实体解析、输入大小界限 |
| pii | 收集依据、字段用途、日志/报告、保留期、访问范围 | 用合成样本测试脱敏，禁止读取真实密钥 |
| permissions | exported、意图过滤器、调用鉴权、权限必要性、WebView | 逐组件核对，APK 元数据不等于权限解析 |
| autostart | 开机接收器、计划任务、启动配置是否确属授权需求 | 只读审计，不新增、启用或破坏启动项 |

## 格式与资源边界

- ELF/PE/DEX 是头字段识别，不验证加载器语义、节/段表、签名或 DEX 校验和。
- ZIP 先限制 EOCD/中央目录字节及实际条目数，再读目录；不调用成员读取/解压接口。只统计条目元数据，大小和压缩比来自可伪造的目录声明。
- ZIP64、多卷、结构不一致、超限归档报未评估；压缩比/展开量阈值只是线索，不是 ZIP bomb 的充分判据。没有成员 CRC、加密内容、嵌套包分析。
- APK 候选由 AndroidManifest.xml + classes*.dex 条目推定；清单内容、证书、签名方案、网络安全配置、资源和 native 库须另行人工检查。
- 源规则是有上限的 UTF-8 单文件正则；会漏掉多行、混淆、包装函数、其他语言模式，会误报注释/示例。500 条截断不能当全覆盖。
- 输入必须是明确授权样本。已知凭据名/目录被拒绝不是通用敏感文件识别器；不要把整个用户主目录设为待扫范围。目录组件并发替换不属于此 CLI 的对抗性保证。
- 本地初始化部署附属资源到 `~/.aharou/builtin-skills/security-audit/`：脚本为 `scripts/audit.py`，本清单为 `references/checklist.md`。不要与用户自定义技能目录混用。实际文件未出现或 SSH 端未同步时明确报告，部署代码存在不等于设备已升级。
